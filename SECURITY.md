# Security policy

## Report a vulnerability

Do not open a public issue for a vulnerability.

Report it in private with [this form](https://github.com/exoego/keycloak-cross-realm-login/security/advisories/new).
You can also find the form under "Report a vulnerability" in the "Security" tab of the repository.

Say which version of the extension and of Keycloak you use, and how to reproduce the problem.

## Supported versions

There is no release yet.
After the first release, only the latest release gets security fixes.
